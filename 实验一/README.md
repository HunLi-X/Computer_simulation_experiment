# 实验一：MATLAB 基础操作

## 实验目的

1. 掌握 MATLAB 的基本操作和语法
2. 学习矩阵和复数运算
3. 理解符号运算与数值运算的区别
4. 掌握变参函数的编写与调用

## 实验内容

### 1. 矩阵与复数运算 (main01.m)

演示了 MATLAB 中矩阵的声明和复数矩阵的操作。

**功能：**
- 定义实数矩阵 A 和复数矩阵 B
- 执行矩阵元素的特定赋值操作

### 2. 符号变量与多项式 (main02.m)

演示了 MATLAB 符号运算工具箱的使用。

**功能：**
- 声明符号变量
- 定义多项式 f(x)
- 使用 `subs` 函数进行变量替换：x → (s-1)/(s+1)
- 对结果进行化简

### 3. 数值计算与符号计算对比 (main03.m)

通过计算组合数 C(50,10) 展示两种计算方法的差异。

**功能：**
- 使用双精度数值方法计算（可能有精度误差）
- 使用符号运算方法计算（保持绝对精确）
- 对比两种方法的计算结果

### 4. 无穷连乘积计算 (main04.m)

使用 `while` 循环计算无穷连乘积，控制精度达到 10^-12。

**功能：**
- 计算 S = Π(1 + 2/n²)，n 从 1 到 ∞
- 使用 while 循环控制计算精度
- 当两次计算的差值小于 10^-12 时停止迭代
- 输出最终结果和迭代次数

### 5. 变参函数应用 (main05.m & mat_add.m)

演示如何编写和调用变参函数。

**功能：**
- `mat_add.m`: 编写变参矩阵加法函数，接受任意数量的矩阵输入
- `main05.m`: 调用 `mat_add` 函数，对多个矩阵进行加法运算

| `main03.m` | 数值与符号计算对比 |
| `main04.m` | 无穷连乘积计算 |
| `main05.m` | 变参函数调用示例 |

| `计算机仿真实验报告模板.doc` | 实验报告模板 |

## 使用方法

在 MATLAB 中运行各个 `main*.m` 文件即可看到对应示例的运行结果。

例如：
```matlab
% 运行示例1
main01

% 运行示例2
main02

% 运行示例3
main03

% 运行示例4
main04

% 运行示例5
main05
```

## 关键知识点

1. **矩阵索引与赋值**: MATLAB 中矩阵的索引和扩展示例
2. **符号运算**: `syms`、`subs`、`simplify` 等函数的使用
3. **数值精度**: 双精度浮点数的精度限制与符号计算的精确性
4. **循环控制**: `while` 循环用于精度控制
5. **变参函数**: 使用 `varargin` 处理可变数量参数

## 预期结果

- `main01.m`: 展示矩阵和复数矩阵的创建与操作
- `main02.m`: 显示多项式变量替换并化简后的 s 函数表达式
- `main03.m`: 显示数值方法和符号方法计算组合数的结果对比
- `main04.m`: 显示无穷连乘积的收敛结果和所需迭代次数
- `main05.m`: 显示多个矩阵相加的结果
